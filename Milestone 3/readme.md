#  FitPlan AI – AI Fitness Plan Generator

**FitPlan AI** is an intelligent web application that helps users create personalized fitness plans. The system generates customized **workout routines** and **dietary plans** based on user information and fitness goals.

The platform provides a simple and clean interface where users can sign up, log in, and manage their fitness plans from a single dashboard. It is designed to make fitness planning easier by providing structured guidance for workouts and nutrition.

##  Features

- User registration and secure login
- Personalized workout plan generation
- Customized dietary plan suggestions
- User dashboard for easy navigation
- Profile management
- Clean and user-friendly interface

##  Purpose

The goal of this project is to provide users with a convenient tool that helps them organize their fitness journey by offering structured workout and diet recommendations.
